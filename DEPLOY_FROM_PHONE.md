# 📱 Deploy from Your Phone (2 Minutes!)

## ✅ Easiest Method: Vercel (Recommended)

### Step 1: Open Vercel on Your Phone
Go to: **https://vercel.com/new**

### Step 2: Sign In
- Tap "Continue with GitHub"
- Sign in with your GitHub account
- Allow Vercel access

### Step 3: Import Repository
- Find: **cmdenter/blank-app**
- Tap "Import"

### Step 4: Configure Project
Fill in these settings:

- **Framework Preset**: Vite
- **Root Directory**: `examples/react-app`
- **Build Command**: `npx vite build`
- **Output Directory**: `dist`

### Step 5: Deploy!
- Tap "Deploy"
- Wait ~1 minute
- Get your live URL! 🎉

Your app will be live at:
```
https://blank-app-XXXXX.vercel.app
```

---

## Alternative: Netlify

### Method 1: Netlify Drop (Super Easy)
1. Go to: **https://app.netlify.com/drop**
2. Drag the `examples/react-app/dist` folder
3. Done! Get instant URL

### Method 2: Netlify GitHub
1. Go to: **https://app.netlify.com/start**
2. Connect GitHub
3. Select **cmdenter/blank-app**
4. Configure:
   - **Base directory**: `examples/react-app`
   - **Build command**: `npm run build`
   - **Publish directory**: `examples/react-app/dist`
5. Deploy!
